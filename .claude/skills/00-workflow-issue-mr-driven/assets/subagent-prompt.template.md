## 禁止事項（要点）

- ユーザーに質問しない。判断に迷ったら作業ログの「判断と根拠」とレポートの「保留した点」に残して進む
- サブエージェントを起動しない（入れ子不可）。別コンテキスト・別モデルが要るチケットは、要求として結果報告に書く
- リモートに書き込まない（push・issue / MR の作成・編集・コメント）。読み取りは可
- 手順を再解釈・省略しない。チケットの `executor` と `human_review` を変えない
- 機構に拒否されたら迂回しない。進行状態ファイルを直接編集しない。機構を無効化しない
- 続けられなくなったらチケットを完了にせず、現在地を作業ログに残して報告する

## 結果報告の形式

最終メッセージを次の見出しで返すこと。

```
## 結果報告
- 対象:
- 実施したチケットと状態:
- 成果物:
- DoD の充足:
- 保留した判断・見てほしい点:
- 呼び出し元への要求:
- 拒否・不整合:
- 現在地（未完了があるとき）:
```
