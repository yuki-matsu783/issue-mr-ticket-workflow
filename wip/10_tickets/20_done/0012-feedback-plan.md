### 判断と根拠

- **設計反映フェーズを立てる**。実装ワークの敵対的レビューと 0010 / 0011 / 0015 の「仕様からの逸脱」が挙げた 11 件は、いずれも実装が仕様より広い / 狭い分で、`docs/` だけで閉じる。放置すると仕様書が実装の説明として使えなくなる
- **AI アセット設計 / AI アセット実装のフェーズは立てない**。`.claude/**` は `scope-limits.json` の `common.protected` で、本 issue のどのフェーズも書き込み許可を持たない。CLAUDE.md も `.claude/` 配下のアセット変更を専用のフェーズ列で進めることを求めている。1 issue = 1 PR の原則からも、別 issue が素直
- **別 issue の作成は本チケットで行わない**。他人も見る場所への投稿は取り消せない外部への副作用で、承認の対象。案の提示に留めた
- **C2（複数ルート・シンボリックリンク・`capabilities`）を対応しないに置いた**。要件にも仕様にも無い挙動の追加で、`docs/` と `src/` の両方の変更が要る。issue #13 の受け入れ条件を超えるため、本 issue で広げない
- **C1（`frontmatter.sh` の引用符の閉じ忘れ）を対応しないに置いた**。本拡張は自前のサブセットパーサで既に対処済みで、機構側の修正はフックが frontmatter を信頼して分岐している箇所の洗い出しが先。判断の材料が足りないため、B1 の起票時に調査対象として添える
