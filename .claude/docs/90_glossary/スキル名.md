# スキル名

### スキルの 3 層構造

スキルを役割・承認方式で 3 層（ワークフロー / ワーク / タスク）に分け、命名 prefix（`00-workflow-*` / `10-work-*` / `20-task-*`）で層を表す分類。層ごとにチェックポイントの承認者（人間 / 敵対的レビューエージェント / セルフレビュー）が決まっている。

- 正典: [CLAUDE.md](../../../CLAUDE.md)「スキルの3層構造」
- 別名・禁止表記: 旧称 `workflow-*` / `work-*` / `task-*`（参考実装の命名。本機構では数字 prefix 付きを使う）

### ワークフロースキル（`00-workflow-*`）

依頼の入口となる振り分けスキル。チェックポイントの承認者は人間。

| スキル名 | 要件書 |
|---|---|
| `00-workflow-issue-mr-driven` | [00-workflow-issue-mr-driven.md](../00_requirements/skills/00-workflow-issue-mr-driven.md) |
| `00-workflow-quick-request` | [00-workflow-quick-request.md](../00_requirements/skills/00-workflow-quick-request.md) |

### ワークスキル（`10-work-*`）

ワーク（計画 / 実施）を実現するスキル。チェックポイントの承認者は敵対的レビューエージェント。

| スキル名 | 要件書 |

| `10-work-design-exec` | [10-work-design-exec.md](../00_requirements/skills/10-work-design-exec.md) |

### タスクスキル（`20-task-*`）

作業レベルの手順を標準化するスキル。チェックポイントの承認者は実行者自身のセルフレビュー。要件書は未作成で、作成時にこの表へ追記する。
