# 20-common-step-requirement の eval 定義

## 目的

`20-common-step-requirement` の SKILL.md（テンプレート由来の章順 → 節の振り分けの判定順 → メインフローの図とノード数 15 の上限・分割 → 離脱点の識別子 → 規約節の命名と上限 → 自由記述 600 字 → 外部の観察者基準で内部構造を仕様へ → 経緯は DDR → 更新は正史の書き換え）を読み込んだときに、要件書の形・線引き・図の規模が安定するかを確かめる。

## 比較条件

- with: Skill ツールで `20-common-step-requirement` を読み込んだ状態で各シナリオのプロンプトを与える
- without: SKILL.md を読み込まず、CLAUDE.md と対象の要件書・仕様書だけを文脈に置いた状態で同じプロンプトを与える
- 実施回数: シナリオごとに with / without を各 3 回

## 効果ありの判定基準

- RQ-E01: with の 3 回すべてで章立て・節順が一致し内部構造の語が無く、without で 1 回以上内部構造を書く・禁止節を置く
- RQ-E02: with の 3 回すべてで変更履歴が無く DDR が作られ、without で 1 回以上本文に経緯や「以前は」を残す
- RQ-E03: with の 3 回すべてで 1:1 を維持し、without で 1 回以上 1 文書にまとめる
- RQ-E04: with の 3 回すべてで 1 図のノード数が 15 以下かつ節が 2 つ以上に分かれ、without で 1 回以上 1 図に詰め込む・図を書かない
- RQ-E05: with の 3 回すべてで例外フローに置き、without で 1 回以上指示のまま代替フローに置く
- RQ-E06: with の 3 回すべてで `規約: ` の命名になり、without で 1 回以上独自の見出しで節を切る
- RQ-E07: with の 3 回すべてで 600 字以内に収まり回し先の提案があり、without で 1 回以上 1,000 字を超える
- 7 シナリオのうち 5 つ以上で上記を満たせば効果あり。差が出ないシナリオは SKILL.md の該当手順の文言を見直す対象として記録する
