# スキル名

### スキルの 3 層構造

スキルを役割・承認方式で 3 層（ワークフロー / タスク / 共通ステップ）に分け、命名 prefix（`00-workflow-*` / `10-task-*` / `20-common-step-*`）で層を表す分類。

### ワークフロースキル（`00-workflow-*`）

依頼の入口となる振り分けスキル。[タスク](./ワークフロー用語.md#タスク)の組み合わせと切れ目の処理を司り、チェックポイントの承認者は人間（MR レビュー または AskUserQuestion）。

| スキル名 | 役割 |
|---|---|
| `00-workflow-issue-mr-driven` | 開発作業。issue と draft MR に紐づけてチケット駆動で進める |
| `00-workflow-quick-request` | 軽作業。範囲を宣言してから進める |

### タスクスキル（`10-task-*`）

タスク（チケットの組み合わせ）を実現するスキル。チェックポイントの承認者は敵対的レビューエージェント（複数チケット完了時点）と、[タスクの切れ目](./ワークフロー用語.md#タスクの切れ目)の MR レビュー。

| スキル名 | タスク |
|---|---|
| `10-task-overall-plan` | 全体計画 |
| `10-task-investigation-plan` | 調査計画 |
| `10-task-investigation-exec` | 調査実施 |
| `10-task-design-plan` | 設計計画 |
| `10-task-design-exec` | 設計実施 |
| `10-task-implementation-plan` | 実装・テスト計画 |
| `10-task-implementation-exec` | 実装・テスト実施 |
| `10-task-feedback-plan` | フィードバック計画 |
| `10-task-design-feedback-plan` | 設計反映計画 |
| `10-task-design-feedback-exec` | 設計反映実施 |
| `10-task-ai-asset-design-plan` | AI アセット設計計画 |
| `10-task-ai-asset-design-exec` | AI アセット設計実施 |
| `10-task-ai-asset-implementation-plan` | AI アセット実装・テスト計画 |
| `10-task-ai-asset-implementation-exec` | AI アセット実装・テスト実施 |
| `10-task-overall-summary` | 全体まとめ |

### 共通ステップスキル（`20-common-step-*`）

チケットの実施で共通に使う作業レベルの手順を標準化するスキル。複数の呼び出し元（タスクの実施・ワークフローの処理）から使われる手順だけをスキル化。

| スキル名 | 役割 |
|---|---|
| `20-common-step-ticket` | チケットの作成・着手・完了・取り消しと、そのテンプレート・スクリプトの提供 |
| `20-common-step-issue` | issue の検索・閲覧・作成・追記（既存の記述・状態は変えない） |
| `20-common-step-feature-mr` | 確定した issue から feature ブランチと draft MR を作成 |
| `20-common-step-commit-push` | 提供コマンド経由でのコミット・push（メッセージ規約・対象の明示・push 前チェック） |
| `20-common-step-worktree` | 作業ツリーの作成・一覧・本流への合流・片付け（提供コマンド経由。既定は切らない） |
| `20-common-step-requirement` | 要件定義書の作成・更新（章立て・EARS の受け入れ基準・正史と経緯の分離） |
| `20-common-step-spec` | 仕様書の作成・更新（要件定義書との 1:1 対応・内部構造の記載） |
| `20-common-step-report-view` | レポート・計画書の HTML ビューの作成・更新（Markdown との同期・機械的検査） |
| `20-common-step-ai-asset-creator` | AI アセット（スキル・フック・ルール・エージェント・settings.json）の標準手順での作成・変更 |
| `20-common-step-shell-script` | sh ファイルの作成・変更（雛形・共通 logger の提供・テスト・検査） |
