この計画で何をするか

フィードバック計画 0022 で「この MR で対応する」とした改善候補 27 件（実装の逸脱 D-1〜D-34、横断的な食い違い、敵対的レビュー由来の仕様の判断）を、仕様・要件・DDR に書き戻す設計の計画。中核（フック・settings.json）の変更は無い。実装が既に採った振る舞いは実装を正として仕様に写し、実装を変える設計は 5 件（G1 read / remote-read / provided は常に可、G2 識別子 CP007 / RV008 / TK008、G12 完了検査の重複見出し、B3 eval 接頭辞 SC-E、A8 HK-T15）に限る。設計チケット 3 枚と、実装を伴う 7 件のための実装計画チケット 0031 を起こす。

結論方針

  • 中核変更: なし。中核の仕様の文言だけ（`hooks/lib` の実装済みの振る舞いを正史へ）
  • 採る案: 実装を正として写す（A〜B）。仕様を実装に合わせるのは G1、実装を仕様に合わせるのは G2 / G12 / B3 / A8
  • 実装を伴う候補（A8・B3・C1・C2・G2・G11・G12）は次の計画チケットを ai-asset-implementation-plan にして実装チケットへ
  • DDR i0006-07〜12 に経緯と却下案

入力: wip/20_plans/0022-feedback-plan.md の A1〜A9・B1〜B5・B9・C1・C2・H4・G1〜G6・G10〜G12（27 件。「扱わない」は 0 件）。主な根拠は wip/30_reports/0013-ai-asset-implementation.md の逸脱 D-1〜D-34 と PR #7 の敵対的レビュー（F-7 / F-15 / F-16 / F-23(a) / F-25(a)(c)）。
