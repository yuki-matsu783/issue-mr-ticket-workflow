# 10-task-ai-asset-design-plan の eval 定義

## 目的

`10-task-ai-asset-design-plan` の SKILL.md（計画タスクの共通手順 + AI アセット設計計画の固有手順）を読み込んだときに、1:1:1 の文書一覧・ヘッドレスの帰結を骨子に含めること・食い違いを計画で決めること・台帳の 1 番号 1 原因の確認・目的文に件数を書かないことが安定するかを確かめる。

## 評価シナリオ

各行は仕様書「テスト観点（eval）」の行と 1:1 に対応する（eval ID が対応の鍵）。

| eval ID | 入力プロンプトと状況 | 期待する振る舞い | 判定方法 | 添付ファイル |
|---------|--------------------|-----------------|---------|-------------|
| ADP-E01 | フック 1 本とそれを呼ぶスキル 1 本の変更を計画する | 1:1:1 の原則で文書の一覧を決め、既存があれば更新・無ければ新規として載せる。経緯は DDR の追加として計画する | 一覧の相対パスと DDR の計画の有無 | `assets/ai-asset-design-plan.template.md` |
| ADP-E02 | 人間の確認・承認を増やす設計（新しい承認ポイント）を含む | ヘッドレス実行での帰結と代替経路を仕様書に書くことを骨子に含める | 骨子にヘッドレスの項目があること | なし |
| ADP-E03 | 調査結果に「実装と仕様が食い違う」候補が 3 件ある | どちらを正とするかを計画の段階で決め、採らなかった案と理由を残す前提で結論方針に書く | 結論方針の記載 | なし |
| ADP-E04 | エラー識別子の台帳を確定するチケットを作る場面 | 完了条件に「1 つの番号が 1 つの原因だけを指すこと」の確認を含める | チケットの DoD | なし |
| ADP-E05 | 次の計画チケット（AI アセット実装計画）の目的を書く場面 | 何を決めるかを書き、枚数などの後で変わる数を書かない | 目的文に件数が無いこと | なし |

## 比較条件

- with: Skill ツールで `10-task-ai-asset-design-plan` を読み込んだ状態で各シナリオのプロンプトを与える
- without: SKILL.md を読み込まず、`CLAUDE.md` と対象の要件書・仕様書だけを文脈に置いた状態で同じプロンプトを与える
- 実施回数: シナリオごとに with / without を各 3 回

## 効果ありの判定基準

- ADP-E01: with の 3 回すべてで 1:1:1 が保たれ、without で 1 回以上まとめた文書を計画する
- ADP-E02: with の 3 回すべてで骨子にヘッドレスの項目があり、without で 1 回以上欠ける
- ADP-E03: with の 3 回すべてで 3 件に正の決定が付き、without で 1 回以上設計チケットへ送る
- ADP-E04: with の 3 回すべてで DoD に確認項目があり、without で 1 回以上欠ける
- ADP-E05: with の 3 回すべてで目的文に件数が無く、without で 1 回以上枚数を書く
- 5 シナリオのうち 4 つ以上で上記を満たせば効果あり。差が出ないシナリオは SKILL.md の該当手順の文言を見直す対象として記録する
