# ドキュメント体系用語

### 正史

その時点で有効な要件・仕様の記述。requirements / spec は正史だけを持ち、検討の経緯・却下案・過去の版は [DDR](#ddr) と git の履歴が持つ。

- 正典: [ai-asset-design-docs.md](../00_requirements/rules/ai-asset-design-docs.md)「正史のみの記述」

### DDR

設計上の決定の記録（背景・決定・理由・却下案・影響）。issue 番号ベースの識別子で命名され、マージ後は本文を変えず frontmatter の状態だけで無効化を表す。

- 正典: [ai-asset-design-docs.md](../00_requirements/rules/ai-asset-design-docs.md)「DDR の運用」

### 用語辞書

機構固有語の定義（意味・目的・関係）の正を集約した `90_glossary/` の文書群。振る舞いの正は requirements / spec が持ち、文書は収録語を定義し直さず初出でここへリンクする。

- 正典: [ai-asset-design-docs.md](../00_requirements/rules/ai-asset-design-docs.md)「用語辞書」

### 横断文書

特定のアセットに紐づかない要件・仕様の文書。`00_requirements/` / `10_spec/` の直下に置かれ、アセットに紐づく文書は種類ごとのサブディレクトリに置かれる。

- 正典: [ai-asset-design-docs.md](../00_requirements/rules/ai-asset-design-docs.md)「配置とアセットとの対応」

### 成果物ルール

`.claude/rules/` のルールの 2 分類の一方。リポジトリに残りレビュー対象になる成果物の書き方を定め、[章スキーマ](#章スキーマ)に従い、観点別レビューの抽出対象になる。

- 正典: [ルール体系.md](../00_requirements/rules/ルール体系.md)「ルールの分類」

### 行動ルール

`.claude/rules/` のルールの 2 分類のもう一方。作業の進め方・その場限りの操作の規約を定める。章スキーマの対象外で、観点別抽出の対象にならない。

- 正典: [ルール体系.md](../00_requirements/rules/ルール体系.md)「ルールの分類」

### 章スキーマ

成果物ルールが持つ固定 7 章（適用範囲 / 構造・配置 / 書式・可読性 / セキュリティ / 堅牢性 / パフォーマンス / テスト・機械的検査）の構成の型。見出し文言と順序が全ルールで揃う。

- 正典: [ルール体系.md](../00_requirements/rules/ルール体系.md)「成果物ルールの章スキーマ」

### 観点章

章スキーマのうちレビュー観点に対応する個々の章。観点別レビューエージェントは、対象ファイルに効く全ルールから担当の観点章だけを抽出して横並びレビューの入力にする。

- 正典: [ルール体系.md](../00_requirements/rules/ルール体系.md)「メインフロー」

### レポート

実施ワークと全体まとめの結果を書く Markdown 文書。同じ名前の [HTML ビュー](#html-ビュー)が併存し、Markdown が正文。`wip/30_reports/` に置かれる。

- 正典: [自己改善ワークフロー機構.md](../00_requirements/自己改善ワークフロー機構.md) F 節

### 計画書

「これから何をするか」だけを書く文書。実施した結果はレポートに分離される。全体計画書と各計画ワークの計画書がある。

- 正典: [自己改善ワークフロー機構.md](../00_requirements/自己改善ワークフロー機構.md) F 節

### HTML ビュー

レポート・計画書の視覚化。テンプレートのコピーと Edit で作られ、ネットワーク接続なしで表示でき、ライト / ダーク両テーマで読める自己完結の HTML。

- 正典: [自己改善ワークフロー機構.md](../00_requirements/自己改善ワークフロー機構.md) F 節

### テンプレート

コピーして使う雛形ファイル。`<名前>.template.md` / `.template.html` / `.template.sh` の命名で機械的に判別され、完成形として正しい frontmatter `type` を含む。

- 正典: [ルール体系.md](../00_requirements/rules/ルール体系.md)「ルールの一覧と取り込む内容」（`markdown-docs` の取り込み内容）
