# 用語辞書

複数の文書で使われ、かつ指し先や表記が揺れうる機構固有語の**定義の正**を集約したディレクトリ。
各設計書は共通の語彙としてこの辞書を前提に書かれ、収録語を定義し直さず初出箇所からここへリンクする。参照の向きは常に設計書 → 辞書で、辞書は設計書へのリンクを持たない自己完結の定義集とする。
振る舞いの要件（When / Shall、判定基準・手順）は requirements / spec が持ち、辞書には書かない。
収録基準・エントリ書式・更新タイミングの詳細は `ai-asset-design-docs` の要件が定める。

## ファイル一覧

| ファイル | 内容 |
|---|---|
| [スキル名.md](./スキル名.md) | スキルの 3 層と各スキル名の一覧 |
| [ワークフロー用語.md](./ワークフロー用語.md) | ワーク・チケット・レビューなど進め方の用語 |
| [ドキュメント体系用語.md](./ドキュメント体系用語.md) | 正史・DDR・ルール・レポートなど文書の用語 |

## エントリの書式

```markdown
### <用語名>

<定義（意味・目的・他の用語との関係。2〜4 行。辞書の中だけで読めて完結する）>

- 別名・禁止表記: <旧称・使わない言い方>（該当時のみ）
```
