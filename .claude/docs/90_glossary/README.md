# 用語辞書

複数の文書で使われ、かつ指し先や表記が揺れうる機構固有語の**定義の正**を集約したディレクトリ。
用語の意味・目的・他の用語との関係はここが正で、各文書は収録語を定義し直さず初出箇所からここへリンクする。
振る舞いの正（When / Shall、判定基準・手順）は requirements / spec が持ち、辞書には書かない。
収録基準・エントリ書式・更新タイミングの正は `../00_requirements/rules/ai-asset-design-docs.md`「用語辞書」節（実装後は `ai-asset-design-docs` ルール本体）。

## ファイル一覧

| ファイル | 内容 |
|---|---|
| [スキル名.md](./スキル名.md) | スキルの 3 層と各スキル名の一覧 |
| [ワークフロー用語.md](./ワークフロー用語.md) | ワーク・チケット・レビューなど進め方の用語 |
| [ドキュメント体系用語.md](./ドキュメント体系用語.md) | 正史・DDR・ルール・レポートなど文書の用語 |

## エントリの書式

```markdown
### <用語名>

<定義（意味・目的・他の用語との関係。2〜4 行）>

- 正典: <その用語の振る舞いを定める requirements / spec へのリンク>
- 別名・禁止表記: <旧称・使わない言い方>（該当時のみ）
```
